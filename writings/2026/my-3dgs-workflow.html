making 3d gaussian splats without an NVIDIA GPU

written 2026-05-16, last updated 2026-05-17

the vast majority of open source software for making 3d gaussian splats (3DGS) requires CUDA, making it unusable for those without an NVIDIA GPU. in the interest of helping people find alternatives, i've decided i should document my 3DGS workflow.

i use MacOS on an Apple Silicon Mac, but none of the software listed below is MacOS-specific.

my workflow

keep in mind the following limitations:

  • splats look bad when viewed from camera positions far from that of the input images.
  • insufficient overlap (<30%) between input images may cause a poor quality or incomplete reconstruction.
  • the lighting conditions at the time of capture will be baked into the splat.
  • the algorithms used struggle with the following:
    • camera: dirty lenses, lens glare/flare, vignetting, chromatic aberration, blur, poor focus, shallow DOF, sensor noise
    • camera settings: inconsistent exposure, inconsistent colors, digital sharpening, compression artifacts
    • environment: movement, large areas of insufficient texture, reflective surfaces
  1. (if applicable) convert inputs into a usable format:
    • HEIC to JPG: for file in *.HEIC; do magick $file -quality 100 -auto-orient $file.jpg; done
    • extract frames from MP4 using sharp-frames: for file in *.mp4; sharp-frames $file --fps 10 --selection-method batched ${file}_images; done (adjust FPS based on the speed of your video; batched selection @ 10 FPS will result in 1 frame every 300-700ms)
  2. open COLMAP
    1. File -> New project
      • specify database location & input image folder
      • click Save
    2. Extras -> Set options for...
      • set dataset type to either "Individual images" or "Video frames"
      • set quality to "Extreme"
    3. Processing -> Feature extraction
      • choose Camera model
      • if all images are taken with the same lens & zoom, enable "Shared for all images"
      • click Extract
    4. Processing -> Feature matching
      • if dataset type is "Individual images" or image count is <1000, use Exhaustive matching
      • if dataset type is "Video frames" and image count is >1000, use Sequential matching
      • click Run
    5. Reconstruction -> Start reconstruction
    6. Extras -> Undistortion
      • specify output folder
      • click Undistort
  3. open Brush
    1. click Directory and choose output folder from last step
    2. (optional) set Training -> steps based on your scene's complexity
    3. set Training -> Max Splats Cap based on your use case (high splat counts improve quality at the cost of rendering performance)
    4. enable Model -> Render mode
    5. set Model -> Render mode to Mip
    6. set Dataset -> Max image resolution to 8192 (arbitrary values can be entered into the textbox next to the slider)
    7. click Start
    8. after training is finished, click Export
  4. (optional) post-process exported PLY file from last step using splat-transform with --filter-cluster --filter-floaters
    • splat-transform's flags are ordering sensitive; swapping the ordering of these flags may cause processing to fail
    • make sure that the output file is also in PLY format to avoid generation loss
  5. open SuperSplat Editor
    1. click File -> Import and choose output PLY file from last step
    2. edit splat as necessary (see SuperSplat User Guide)
    3. File -> Export -> PLY
  6. final PLY file can be lossily compressed to SOG using splat-transform

if COLMAP crashes at any point during step 2, the project database should be deleted and the entirety of step 2 should be redone before continuing on to further steps.

on my hardware (Apple M4 Pro w/ 48GB RAM), i find that it usually takes 2-8 hours to turn input images to a finished splat.

determining ideal step count

complete workflow steps 1 and 2 as normal. then, do the following:
  1. open Rerun Viewer
    1. click rerun -> Open file... and select the brush_blueprint.rbl file located within the root of brush's repository
  2. open Brush
    1. click Directory and choose COLMAP output folder
    2. set Training -> steps to 300k
    3. set Training -> Max Splats Cap based on your use case (high splat counts improve quality at the cost of rendering performance)
      • the same value must be used during the second Brush run
    4. enable Model -> Render mode
    5. set Model -> Render mode to Mip
    6. set Dataset -> Max image resolution to 8192
    7. enable Dataset -> Split dataset for evaluation
    8. enable Rerun.io -> Enable rerun
    9. click Start
    10. after splat training completes, delete any output folders created by Brush
  3. analyze logged values in Rerun Viewer
    • SSIM and PSNR are the two logged measures of visual quality (both are higher = better)
    • focus on analyzing the mean values for all eval images rather than rather than trying to analyze the results for every eval image independently
    • your goal is to find the lowest step count that gives you the best possible visual quality; training beyond the point where these values plateau can cause the splat to overfit to the input images, worsening visual quality at novel positions
  4. proceed with the remaining steps in the workflow, making sure to use the ideal step count determined from this analysis
