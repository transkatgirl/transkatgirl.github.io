making 3d gaussian splats without an NVIDIA GPU

written 2026-05-16, last updated 2026-05-17

the vast majority of open source software for making 3d gaussian splats (3DGS) requires CUDA, making it unusable for those without an NVIDIA GPU. in the interest of helping people find alternatives, i've decided i should document my 3DGS workflow.

i use MacOS on an Apple Silicon Mac, but none of the software listed below is MacOS-specific.

my workflow

keep in mind the following limitations:

  • splats look bad when viewed from camera positions far from that of the input images.
  • insufficient overlap (<30%) between input images may cause a poor quality or incomplete reconstruction.
  • the lighting conditions at the time of capture will be baked into the splat.
  • the algorithms used struggle with the following:
    • camera: dirty lenses, vignetting, chromatic aberration, blur, sensor noise
    • camera settings: inconsistent exposure, inconsistent colors, digital sharpening, compression artifacts
    • environment: movement, insufficient texture
  1. (if applicable) convert HEIC to JPG: for file in *.HEIC; do magick $file -quality 100 -auto-orient $file.jpg; done
  2. (if applicable) extract frames from MP4 using sharp-frames: for file in *.mp4; sharp-frames $file --fps 10 --selection-method batched ${file}_images; done (adjust FPS based on the speed of your video; batched selection @ 10 FPS will result in 1 frame every 300-700ms)
  3. open COLMAP
    1. File -> New project
      • specify database location & input image folder
      • click Save
    2. Extras -> Set options for...
      • set dataset type to either "Individual images" or "Video frames"
      • set quality to "Extreme"
    3. Processing -> Feature extraction
      • choose Camera model
      • if all images are taken with the same lens & zoom, enable "Shared for all images"
      • click Extract
    4. Processing -> Feature matching
      • if dataset type is "Individual images", use Exhaustive matching
      • if dataset type is "Video frames", use Sequential matching
      • click Run
    5. Reconstruction -> Start reconstruction
    6. Extras -> Undistortion
      • specify output folder
      • click Undistort
  4. open Brush
    1. click Directory and choose output folder from last step
    2. set Dataset -> Max image resolution to 8192
    3. set Training -> Max Splats Cap based on your use case (high splat counts improve quality at the cost of rendering performance)
    4. if your scene is very complex, consider increasing Training -> steps
    5. click Start
    6. after training is finished, click Export
  5. (optional) post-process exported PLY file from last step using splat-transform with --filter-cluster --filter-floaters
    • splat-transform's flags are ordering sensitive; swapping the ordering of these flags may cause processing to fail
    • make sure that the output file is also in PLY format to avoid generation loss
  6. open SuperSplat Editor
    1. click File -> Import and choose output PLY file from last step
    2. edit splat as necessary (see SuperSplat User Guide)
    3. File -> Export -> PLY
  7. final PLY file can be lossily compressed to SOG using splat-transform

on my hardware (Apple M4 Pro w/ 48GB RAM), i find that it usually takes 2-5 hours to turn input images to a finished splat.
